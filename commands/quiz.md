description: ออกข้อสอบทีละข้อจาก topic หรือไฟล์ — ตอบแล้วเฉลยทันที
argument-hint: "[topic or file path]"
---

ออกข้อสอบเกี่ยวกับ "$ARGUMENTS":

ถ้า argument เป็น path → อ่านไฟล์จริงแล้วออกข้อสอบจากเนื้อหาในไฟล์

กฎ:
- ถามทีละ 1 ข้อ — รอผู้ใช้ตอบก่อนถามข้อถัดไปเสมอ
- จำนวนข้อไม่กำหนดตายตัว — ตัดสินจากความกว้าง/ความซับซ้อนของเรื่อง เรื่องเล็กอาจ 3 ข้อ เรื่องใหญ่อาจเกิน 10 ข้อ ตั้งเป้าให้ครอบคลุมประเด็นสำคัญของเรื่อง ไม่ใช่ครบตามจำนวน
- ปนรูปแบบ: ตัวเลือก / เติมคำ / อธิบายสั้น / เจอโค้ดหรือสถานการณ์แล้วตอบว่าเกิดอะไรขึ้น
- ไล่จากง่าย → ยาก ข้อหลังต่อยอดจากข้อก่อน
- ผู้ใช้ตอบแล้ว → บอกทันทีว่าถูก/ผิด + เหตุผลสั้นๆ แล้วถามข้อถัดไปในข้อความเดียวกัน
- ผู้ใช้ตอบผิดซ้ำในประเด็นเดียวกัน → แทรกข้อทบทวนประเด็นนั้นก่อนไปต่อ
- คำสั่งกลางทางที่ต้องรองรับ: "ยากขึ้น" / "ง่ายลง" / "ข้าม" / "เฉลย" / "พอ" / "อีก N ข้อ"
- จบชุด → สรุปคะแนน + ประเด็นที่ตอบผิดและควรทบทวน

เริ่มด้วยข้อแรกเลย — ไม่อธิบายกฎ ไม่บอกจำนวนข้อล่วงหน้า
ภาษา: ตาม input
