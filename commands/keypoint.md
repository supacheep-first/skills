สรุปประเด็นหลักของ "$ARGUMENTS" ในรูปแบบ:

- ระบุประเด็นหลัก 3-5 ข้อ
- แต่ละข้อมี supporting detail สั้น (1-2 ประโยค)
- จบด้วย "Takeaway" — 1 ประโยคที่นำไปใช้ได้จริง

แนวทาง:
- ใช้ภาษาเดียวกับ input
- หลีกเลี่ยง jargon ที่ไม่จำเป็น
- ถ้าหัวข้อเป็นเรื่อง real-time (ราคา, ข่าว, เวอร์ชันล่าสุด) ให้ web search ก่อน
- ถ้าข้อมูลไม่ครบให้บอกตรง ๆ อย่าเดา
