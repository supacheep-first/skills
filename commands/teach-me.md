สอน "$ARGUMENTS" แบบ progressive 3 layers:

## Layer 1 — Foundation
- mental model พื้นฐาน
- ตัวอย่าง 1 ตัวที่ชัดที่สุด
- 1 คำถาม check ความเข้าใจ (ให้ผู้ใช้ตอบ)

## Layer 2 — Intermediate
- complication ที่เพิ่มเข้ามาจาก foundation
- common patterns ที่เจอในงานจริง
- 1 คำถามที่ลึกขึ้น

## Layer 3 — Advanced
- edge cases, pitfalls, expert insights
- เมื่อไหร่ pattern พื้นฐานใช้ไม่ได้
- next steps สำหรับเจาะลึกต่อ

## Where to go next
- 2-3 resources/topics ที่ควรไปต่อ

แนวทาง:
- หยุดหลัง Layer 1 ถามว่า "พร้อมไป Layer 2 ไหม" ถ้า input ไม่ได้บอกว่าเอาทั้งหมด
- ถ้า input บอก "ทั้งหมด" หรือ "เต็ม" → ลงครบ 3 layers
- ใช้ตัวอย่างเดียวที่ขยายความซับซ้อนขึ้นทุก layer (continuity)
- ภาษาตาม input
